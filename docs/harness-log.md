# Decision and harness log

Meaningful decisions by Simon or an agent that do not belong in the PROD, DES or TECH logs, and meaningful failures of the harness itself: wrong agent behaviour, poor reviews, missed requirements, redundant handovers, skill conflicts, excessive context use, a failure mode that keeps coming back. Each entry gives the decision or failure, the reasoning or cause, the corrective action, and the outcome once it is known. Minor interactions do not go here. Entries are never rewritten, only amended with an outcome.

When several entries point at the same cause, that is the moment to change a skill, an agent or `CLAUDE.md`, and to say so in a new entry.
